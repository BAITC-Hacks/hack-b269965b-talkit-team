# Фаза 0 — основа и границы

## Задание

1. Прочитай текущий репозиторий и инструкции starter. Посмотри package.json, lockfile, server.ts/app.ts, Vite proxy, build/Docker и docs/runbooks/VALIDATION.md. Не считай архив ранее полностью проверенным. Запусти существующий check/verify. Если зависимостей нет, установи по принятому lockfile; если lockfile действительно отсутствует, создай его настоящей установкой. Не обновляй всё на latest.
2. Помести исходный комплект в data/voice-router, не меняя ID, разметку и формулы. Прочитай README и все JSON, особенно not_this_if, actions, irreversible, handoff и примеры preview/execute. Используй meta.as_of_date как дату симуляции.
3. Найди реально доступные адаптеры TalkIt DSR, OpenAI STT/VAD, gpt-realtime и ElevenLabs V3. Зафиксируй исходные пути, зависимости, точные model IDs, транспорт, формат аудио, способ отмены и авторизации. Импортируй только разрешённые маленькие адаптеры. Если кода нет, сообщи интегратору конкретный блокер; не выдумывай существующий API.
4. Зафиксируй общие DTO в src/shared/voice-router.ts: TurnInput, RouteDecision, TurnResult, TraceEvent. Поля каталога сохраняй: scenarios[], alternatives[], language, slots, is_continuation. В сценарию: scenario_id, confidence, reason. Разрешённые ID загружать из каталога. Новые технические поля явно считать расширениями приложения.
5. Введи sessionId и turnId, выбранный текст, метаданные происхождения STT и состояния провайдеров. У одного пользовательского хода один окончательный результат. Раздели распознанный язык ru/kk/mixed и язык ответа ru/kk.
6. Добавь server-only настройки провайдеров с безопасными примерами. Не требуй живых API-ключей для unit-тестов/сборки. Не заставляй импорт серверных speech-настроек через общий readConfig ломать Vite. Отсутствующий ключ отображать как неготовую интеграцию, не как успешный мок.
7. Прочитай существующий корневой TASK.md и его приёмку. Не перезаписывай полное задание короткой заметкой. Текущий незакрытый критерий запиши в docs/STATUS.md; результаты проверки — отдельным файлом в docs/progress/. Обнови docs/compliance/PREEXISTING.md и docs/implementation/OWNERSHIP.md только по фактическим данным.

## Проверка

Существующий проект запускается и проходит доступные проверки. Каталог реально загружается. Исходные тесты сохранены. Есть список реальных речевых адаптеров либо честно обозначенные блокеры; наличие ключа не выдаётся за проверенное подключение.

## Не делать

Новый каркас, замену H3, перенос платформы TalkIt, проектирование универсального SDK и многочасовой архитектурный аудит.
