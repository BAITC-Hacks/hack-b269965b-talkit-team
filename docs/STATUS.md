## Реализовано в коде

- Текстовый путь: Vue → HTTP turn/reset → `gpt-realtime` → проверка каталога, policy и ответ по данным. Есть повторное использование соединения, прямые ответы для безопасных случаев и eval runner.
- Голосовой путь: browser WebSocket, OpenAI STT/VAD, Yandex STT, DSR, ElevenLabs V3, PCM capture/playback и общий контракт `src/shared/voice.ts`.
- Веб-страница Voice Router с голосовым и резервным текстовым вводом: правая trace-панель показывает последний результат text/voice без повторного запроса. `route.completed` передаёт решение до TTS, `turn.completed` — итог озвучки. Контекст каналов пока раздельный. [Отчёт upstream](progress/2026-09-23_17-46_codex_early-route-result.md).
- В upstream приняты корректировки VAD/EOU и границ STT, ожидания авторитетного OpenAI final, безопасная диагностика TTS (`kind`/HTTP-статус) и начало аудио только с первым PCM-фреймом. [STT-отчёт](progress/2026-09-23_17-32_codex_stt-orchestration.md), [TTS-отчёт](progress/2026-09-23_17-24_codex_tts-failure-diagnostics.md), [trace-отчёт](progress/2026-09-23_17-37_codex_voice-router-trace.md).
- Каталог из 40 сценариев и 3 системных намерений; исходный набор остаётся неизменным. Дата симуляции — `2026-10-01`.
- Локальные исправления интегрированы с новым transport: корректная фаза ресемплинга, timeout начала воспроизведения, неизменяемый результат и отдельные лимиты microphone/TTS frames.

Наличие реализации не подтверждает live-приёмку.
