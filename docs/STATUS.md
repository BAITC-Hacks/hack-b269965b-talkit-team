## Реализовано в коде

- Текстовый путь: Vue → HTTP turn/reset → `gpt-realtime` → проверка каталога, policy и ответ по данным. Есть повторное использование соединения, прямые ответы для безопасных случаев и eval runner.
- Голосовой путь: browser WebSocket, OpenAI STT/VAD, Yandex STT, DSR, ElevenLabs V3, PCM capture/playback и общий контракт `src/shared/voice.ts`.
- Веб-страница Voice Router с голосовым и резервным текстовым вводом, трассировкой и состояниями провайдеров.
- Каталог из 40 сценариев и 3 системных намерений; исходный набор остаётся неизменным. Дата симуляции — `2026-10-01`.
- Локальные исправления интегрированы с новым transport: корректная фаза ресемплинга, timeout начала воспроизведения, неизменяемый результат и отдельные лимиты microphone/TTS frames.

Наличие реализации не подтверждает live-приёмку.
