## Текущая задача и следующий шаг

- Активная фаза: Phase 0. В коде есть DTO, серверный catalog loader, server-only provider config и тесты. Продуктового HTTP/LLM/voice пути пока нет.
- `CI=true pnpm run verify` прошёл: 36 тестов, build и built smoke. Каталог загрузился также из собранного серверного модуля.
- `data/voice-router` присутствует и валиден, но пока не отслеживается Git. Dockerfile настроен включать его в runtime; Docker engine недоступен, контейнер не проверен.
- Следующий критерий: подтвердить происхождение/право включения комплекта и доступ к `gpt-realtime`, затем реализовать Phase 1 по [плану](implementation/phases/01_TEXT_PIPELINE.md).
- Разрешение на pre-existing starter и перенос внутреннего речевого кода остаётся неподтверждённым. Ключи и живые API не проверены.
