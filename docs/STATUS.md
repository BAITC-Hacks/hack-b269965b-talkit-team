## Текущая задача и следующий шаг

- Активная фаза: Phase 1. Локальная реализация завершена; live-приёмка остаётся открытой.
- На совместном дереве прошли `typecheck`, один запуск 67 тестов, production build и built smoke. После новых browser-voice-тестов общий `check` дал 70/71 из-за локального fake WebSocket; полный `verify` остановился на форматировании параллельных voice/UI-файлов.
- Docker image Phase 1 собран; внутри прошли check/build, а runtime-контейнер прошёл HTTP smoke, Voice Router unavailable path и reset.
- Следующий шаг по задержке: подключать Realtime-роутер уже при начале браузерного звонка после стабилизации голосового транспорта; затем измерить cold/warm routing, качество и задержку до воспроизведения.
- Live-eval требует контроля доступа и разрешения расходовать quota; без него реальная задержка и исходный evaluator не подтверждены.
- Разрешение на pre-existing starter и перенос внутреннего речевого кода остаётся неподтверждённым. Непустой `OPENAI_API_KEY` обнаружен без вывода значения; живой API ещё не вызывался.
