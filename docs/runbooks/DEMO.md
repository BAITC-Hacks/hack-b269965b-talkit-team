# План демонстрации

> Перенесено из исходного starter. Это инструкция/шаблон, а не доказательство текущей готовности Voice Router. Актуальные результаты — в `docs/STATUS.md` и `docs/progress/`.

Шаблон без заранее подготовленного предметного решения.

1. Пользователь и проблема одной фразой.
2. Показать входные данные, не скрывая их происхождение.
3. Запустить один реальный сквозной сценарий.
4. Показать проверяемый результат и его отличие от альтернатив.
5. Объяснить текущие ограничения и следующий шаг.

Подготовьте запасную запись после появления рабочего конкурсного сценария. Запись не заменяет обязательный работающий деплой.
Данные в demo должны быть синтетическими либо разрешёнными к публикации.
