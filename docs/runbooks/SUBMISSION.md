# Контроль перед сдачей

> Перенесено из исходного starter. Это инструкция/шаблон, а не доказательство текущей готовности Voice Router. Актуальные результаты — в `docs/STATUS.md` и `docs/progress/`.

- Весь новый код и артефакты находятся в выданном репозитории.
- Ранее созданный starter и материалы раскрыты; разрешение организатора сохранено.
- Для каждого отчётного часа есть фактический прогресс и пройдена требуемая проверка.
- pnpm install --frozen-lockfile проходит на чистой копии.
- pnpm run verify проходит; результат не заявляется без запуска.
- Проект развёрнут; адрес, инструкции и тестовый доступ предоставлены безопасным способом.
- В инкогнито на другом устройстве работает главный сценарий. Нужные ключи не привязаны к браузеру капитана.
- README описывает конкурсный продукт, а не один лишь starter.
- Лимиты API/баланс/сроки ключей позволяют судьям проверить реальную функцию.
- Production TalkIt и клиентские данные недоступны конкурсному проекту без явной необходимости и разграничения прав.
- На дедлайне зафиксированы commit и deployment. Дальнейшие изменения — только при разрешении организатора.
- Сервис остаётся доступным весь период проверки; точные требования к сроку доступности уточнены.
