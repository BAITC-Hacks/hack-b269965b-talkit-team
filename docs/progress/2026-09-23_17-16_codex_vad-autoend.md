# Автоматическое завершение голосовой реплики по VAD

Фактическое время записи: 23 сентября 2026, 17:16, Asia/Qyzylorda (UTC+05:00).

## Изменения

- Существующий OpenAI STT уже получал `input_audio_buffer.speech_stopped`, но голосовой сервер игнорировал его для завершения реплики. Теперь сервер передаёт `vad.speech_stopped` с идентификатором хода и item ID через существующий WebSocket-контракт; браузер один раз выполняет обычный `audio.stop`. Ручная кнопка остаётся запасным вариантом.
- Принятый DSR-текст в панели выделен зелёным. Частичные STT-гипотезы не выдаются за принятые.
- Yandex STT удерживает финальные фрагменты, пришедшие до `commit`, и не смешивает аудио соседних реплик при незавершённом EOU. OpenAI STT при сбое закрывает старые WebSocket и конвертер, чтобы они не передавали аудио в новую сессию.
- Код доступа в UI и серверном голосовом протоколе не восстанавливался по явному решению пользователя. Проверка Origin и лимиты не являются аутентификацией; перед публичным запуском платных API требуется внешнее ограничение доступа и расходов.

## Проверки и ограничения

- `pnpm run check` прошёл: типы и 86/86 тестов. После параллельных изменений `pnpm run verify` прошёл: doctor, формат, типы, 85/85 тестов, production build и built smoke. Разница в числе тестов связана с изменением рабочего дерева между прогонами; оба указанных результата фактические.
- Тест браузера проверяет совпадение turn ID, повторное VAD-событие и гонку с ручной остановкой. Тесты Yandex покрывают финал до `commit` и незавершённый EOU.
- Платные STT/TTS не вызывались в этих проверках. Позднее пользователь сообщил результат живого звонка: DSR выбрал Yandex до финала OpenAI, а TTS завершился `failed` без воспроизведения. Причина DSR — окно агрегирования OpenAI 600 мс при ожидании второго провайдера DSR 300 мс. Точный сбой TTS неизвестен: текущий обработчик отбрасывает категорию ошибки и HTTP-статус. Это не является успешной live-приёмкой голоса.

Следующий шаг: согласовать время ожидания DSR с выдачей финала OpenAI и добавить безопасную диагностику TTS без сохранения ключа, текста или сырого ответа провайдера; затем повторить контролируемый живой звонок.
